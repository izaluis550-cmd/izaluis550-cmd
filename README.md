## Objetivo

Aplicar los conceptos básicos de versionamiento con Git y GitHub para gestionar
los cambios de un proyecto sencillo.

## Contenido

- `index.html`: página del proyecto, con los datos de la estudiante, los pasos
  del trabajo y lo aprendido.
- `README.md`: esta descripción.

## Historial de trabajo

1. Se crea `index.html` con la estructura básica.
2. Se agregan un título y un párrafo de presentación.
3. Se agregan los datos de la estudiante y los pasos del trabajo.
4. Se agrega este README.
5. En la rama `estilos` se agregan los estilos CSS, y luego se fusiona con `main`.

## Cómo verlo

Descarga o clona el repositorio y abre `index.html` en el navegador.
